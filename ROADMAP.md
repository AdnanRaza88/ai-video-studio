# Roadmap

## Phase 1 — Foundation (done in repo structure)
- [x] Multi-platform layout (Flutter, CLI, docs)
- [x] Light UI shell (prompt + models + progress)
- [x] Model manifest + in-app / CLI download flow
- [x] OSS docs (README, CONTRIBUTING, ROADMAP)

## Phase 2 — Core generation
- [ ] Real Hugging Face model entry (small open T2V / I2V)
- [ ] CLI: download + invoke local runtime
- [ ] Flutter: same model store + progress events
- [ ] Save MP4 to gallery / folder

## Phase 3 — Platforms
- [ ] Stable Android APK via CI
- [ ] Flutter web polish
- [ ] Desktop (Flutter or CLI+GUI)
- [ ] iOS build path

## Phase 4 — Polish
- [ ] Better light UI / accessibility
- [ ] Cancel, resume download
- [ ] Multiple models, device capability hints
- [ ] Contributor-friendly examples and tests

## Non-goals (near term)
- Photorealistic cinema-grade video on low-end phones
- Mandatory cloud accounts
- Closed proprietary model lock-in
