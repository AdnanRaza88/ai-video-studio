# AI Video Studio

**Open-source, local-first AI video studio** — prompt in, multi-scene video out.

Short scenes are planned and generated by a **LangGraph agent pipeline**, then stitched into a longer video (5 seconds up to ~10 minutes). Seed and character controls help keep style consistent.

No signup. Models download in-app / CLI. APK builds via GitHub Actions.

| Platform | Status |
|----------|--------|
| Android APK | Flutter + CI |
| Desktop CLI | Python + LangGraph |
| Web | Flutter web target |
| iOS | Planned |

## Features

- **Agentic pipeline** (LangGraph): plan scenes → generate clips → consistency check → stitch
- **Duration control**: 5s → 10 min (short clips combined)
- **Seed + character** for consistency
- **Clay / soft UI** — friendly, no accounts
- **Model manager** — download open models (demo + LTX / CogVideoX / AnimateDiff slots)
- Optional future: user-provided cloud video APIs

## Quick start — CLI

```bash
cd cli
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt

python -m ai_video_studio list-models
python -m ai_video_studio download demo-t2v

python -m ai_video_studio generate \
  "a cute rabbit counting flowers in a garden" \
  --model demo-t2v \
  --duration 60 \
  --seed 42 \
  --character "orange rabbit with blue scarf"
```

Outputs land under `~/.ai-video-studio/outputs/`.

## Quick start — Android / Web

```bash
cd flutter
flutter pub get
flutter run
flutter build apk --release
```

Or download APK from **Actions → Build APK → Artifacts**.

## Architecture (agent graph)

```
User prompt + duration + seed + character
        │
        ▼
  plan_scenes ──────────────► scene list
        │
        ▼
  generate_clip ◄──┐   (loop per scene)
        │          │
        ▼          │
  consistency_check ┘  (retry with new seed if needed)
        │
        ▼
     stitch  → final video (FFmpeg in production)
```

Real open models (LTX-Video 2B, CogVideoX-2B, AnimateDiff) plug into `generate_clip`. Desktop GPU recommended for full weights.
